# Contextual Comunicacao — previa

Previa estatica para avaliacao do cliente: https://jcgoliver21.github.io/contextual-comunicacao/

HTML, CSS e JavaScript foram reconstruidos. O conteudo corresponde ao backup de 27/07/2025.
As imagens foram reprocessadas e revisadas. Este repositorio contem somente os arquivos publicos
da replica; nao contem PHP, SQL, o perfil FTP, usuarios, credenciais ou codigo da aplicacao antiga.

O formulario prepara uma mensagem no aplicativo de e-mail do visitante; ele conclui o envio.
Nao ha backend, upload ou painel WordPress. Os videos carregam o player do YouTube somente apos clique.
A politica de privacidade preserva o texto historico e precisa de revisao antes de uma publicacao definitiva.

O site original estava indisponivel: igualdade visual pixel a pixel nao foi confirmada.
Esta previa inclui metadados noindex e politica de seguranca de conteudo. A versao estatica de origem
passou por ClamAV com assinaturas de 03/10/2026: 266 arquivos verificados, nenhuma deteccao.
Essas verificacoes reduzem os riscos identificados; nao constituem garantia de risco zero.

Publicacao: branch main, raiz do repositorio, GitHub Pages. A pasta assets contem o visual e as interacoes.
